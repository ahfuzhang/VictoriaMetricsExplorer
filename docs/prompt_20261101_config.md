# 目标

实现一个在插件 APP 进程中读取配置文件的功能。

# 步骤

首先通过容器的环境变量传入一个路径，这个路径底下会有很多的 .yaml 文件。

APP 的进程启动的时候，会通过这个环境变量把目录下的所有 yaml 文件读到内存当中。

这些 YAML 文件配置的内容就是所有已知的 metric，比如说 CPU 的占用率。我会把一个代表 CPU 占用率的 metric 配置成当前的 CPU 占用曲线，以及 CPU 占用百分比。这些信息我会提前配置在 YAML 文件中，当遇到这一类的 metric 时，就会以约定的形式来展示这些数据。

例如：process_cpu_seconds_total 这个指标是 cpu 的秒数。

```promql
sum by () (rate({__name__="process_cpu_seconds_total",pod=~"vminsert-vmcluster-realtime-.*"}[1m]))
```

上面的查询就等于 CPU 占用率。
单位是百分比。

我希望在配置文件中配置:

* metric name
* 查询表达式
* 单位
* 描述
* 图形的样式：曲线图，堆积曲线图，双坐标曲线图 等

等信息。

然后把以上的配置全部加载到内存中。
当用户以 By Pod 的模式进入后，顶部就展示配置中的已知的各种曲线图。

最终，随着我的配置越来越丰富，整个系统的专业化程度就会越高。
并且显得越智能。
各种常见的指标，会以默认最佳的模式展示出来。

# 配置文件要求

* 存在多个配置文件，每个配置文件对应一种大的类别
* 每个配置文件存在多个配置项，一个配置项对应一个图形
